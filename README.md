# 💸 RupeeTracker

A lightweight, offline-first expense tracker built for Indian students and early professionals. No login, no cloud, no nonsense — just open your browser and track your money.

![License](https://img.shields.io/badge/license-MIT-blue.svg)
![PRs Welcome](https://img.shields.io/badge/PRs-welcome-brightgreen.svg)
![Made for GSSoC](https://img.shields.io/badge/Open%20Source-GSSoC%20Ready-orange)

---

## ✨ Features

- 📊 Visual spending breakdown by category
- 🗂️ Categories: Food, Transport, Education, Entertainment, Health, Others
- 📅 Filter by month
- 💾 Data saved locally in your browser (no account needed)
- 📤 Export expenses to CSV
- 🌙 Dark/Light mode toggle
- 📱 Fully responsive

---

## 🚀 Getting Started

No install needed. Just clone and open in your browser.

```bash
git clone https://github.com/YOUR_USERNAME/rupee-tracker.git
cd rupee-tracker
open index.html    # or double-click index.html
```
