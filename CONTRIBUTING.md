# Contributing to RupeeTracker 🙌

Thank you for your interest in contributing! This document will help you get started.

---

## 🐛 Reporting Bugs

Open an [Issue](../../issues) and include:
- Steps to reproduce
- What you expected vs. what happened
- Browser and OS version
- Screenshot if possible

---

## 💡 Suggesting Features

Open an Issue with the `enhancement` label. Describe:
- The problem this solves
- Your proposed solution
- Any alternative approaches

---

## 🔧 Making Code Changes

1. **Fork** the repository
2. **Clone** your fork:
   ```bash
   git clone https://github.com/YOUR_USERNAME/rupee-tracker.git
   ```
3. **Create a branch** for your change:
   ```bash
   git checkout -b feature/your-feature-name
   ```
4. **Make your changes** and commit:
   ```bash
   git commit -m "feat: add recurring expense support"
   ```
5. **Push** and open a **Pull Request**

---

## 📋 Commit Message Guide

Use this format:
```
type: short description
```

Types: `feat`, `fix`, `docs`, `style`, `refactor`, `test`, `chore`

Examples:
- `feat: add CSV export`
- `fix: chart not rendering on mobile`
- `docs: update setup instructions`

---

## ✅ PR Checklist

Before submitting, make sure:
- [ ] Your code works in Chrome, Firefox, and Safari
- [ ] Mobile layout is not broken
- [ ] You've added/updated comments where needed
- [ ] README is updated if you added a new feature

---

## 🧑‍💻 Good First Issues

Look for issues labelled `good first issue` — these are beginner friendly and well-scoped.

---

We appreciate every contribution, big or small. Happy coding! 🚀
